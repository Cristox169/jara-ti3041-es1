# CrisSteel - Catálogo online

Proyecto individual para la Evaluación Sumativa 1 de Programación Back End (TI3041).
La solución presenta el catálogo estático de una ferretería local mediante Django y datos JSON cargados desde la vista.

## Preparación local

1. Crear y activar un entorno virtual.
2. Instalar las dependencias con `pip install -r requirements.txt`.
3. Ejecutar `python manage.py runserver`.
